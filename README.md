# Life Skills Academy: Know It

A phone-first family game that fixes common life skill myths. Each card is a real moment where the gut answer is wrong. Pick an answer, say how sure you are, then see the fix and its source.

Live: https://passingby5.github.io/life-skills-academy/

- Decks: First Aid, Kitchen and Food, Money, Scam Defense. Each has 50+ cards for young adults (15 to 30) and adults (30+).
- Every card cites a real public source (NHS, CDC, USDA, CFPB, IRS, SSA, FTC, and others). See REVIEW.md.
- Works offline. Progress stays on your phone.
- Spec: SPEC.md. Build: `node build.js`. Deploy: `tools/deploy.sh` (normal push of site/ to the gh-pages branch). Tests: `npm test` (needs playwright-core and Chrome).

General info only, not medical, legal or money advice. In an emergency call 911.
